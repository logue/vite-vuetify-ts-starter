This template helps you get started developing with Vue 3 and TypeScript on the [Vite+](https://viteplus.dev/) toolchain (Vite, Rolldown, Vitest, Oxlint, Oxfmt). It uses Vue 3 `<script setup vapor>` SFCs; check out the [script setup docs](https://vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

Includes [vue-router](https://router.vuejs.org/) and [Pinia](https://pinia.vuejs.org/).

Additionally, [Oxlint](https://oxc.rs/docs/guide/usage/linter) and [Oxfmt](https://oxc.rs/docs/guide/usage/formatter) are included and set to run automatically at runtime and on commit (`vp staged` via the `.vite-hooks/pre-commit` Git hook). Type checking and type-aware linting are powered by [vize](https://www.npmjs.com/package/vize) with TypeScript 7. (These settings are strict, so relax them as needed.)

When the development server runs, it is checked in real-time by [vite-plugin-checker](https://github.com/fi3ework/vite-plugin-checker).

First, define `VITE_APP_TITLE` in your `.env` file.

## 🚀 Quick Start

### Installation

```bash
pnpm install
```

### Start Development Server

```bash
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

```bash
pnpm build
```

### Test

```bash
pnpm test:run
pnpm test:e2e
```

## ✨ Features

- **Vue 3** + **TypeScript** + **Vite+** combination
- Routing and state management with **vue-router** and **Pinia**
- Code quality management with **Oxlint** and **Oxfmt**
- Unit testing with **Vitest**
- E2E testing with **Playwright**
- Real-time type checking with **vite-plugin-checker**
- Strict linter settings to maintain high-quality code

## 📋 Commands

Designed to be close to [create-vue](https://github.com/vuejs/create-vue-templates/tree/main/typescript-router-pinia-vitest-playwright-eslint) commands.

| Command          | Description                                        |
| ---------------- | -------------------------------------------------- |
| `dev`            | Start development server                           |
| `lint`           | Run all linters (vize, Oxlint, Oxfmt)              |
| `lint:check`     | Run type-aware lint with vize                      |
| `lint:oxlint`    | Run Oxlint (with autofix)                          |
| `lint:oxfmt`     | Format with Oxfmt                                  |
| `test`           | Run Vitest                                         |
| `test:run`       | Run unit tests once                                |
| `test:coverage`  | Run unit tests once and output coverage report     |
| `test:e2e`       | Run Playwright E2E tests                           |
| `build`          | Type-check and build for production                |
| `build:analyze`  | Execute Bundle Analyzer                            |
| `build:clean`    | Clear production build files                       |
| `build-only`     | Build for production without checking (for deploy) |
| `clean`          | Clear artifacts                                    |
| `clean:hard`     | Clear artifacts and development cache              |
| `type-check`     | Type-check with vize (`tsconfig.app.json`)         |
| `preview`        | Run the program generated by the production build  |
| `skills:install` | Install AI agent skills from `skills-lock.json`    |
| `skills:update`  | Update AI agent skills                             |

## 🐛 Troubleshooting

When adding or deleting files, an error may occur, and even if corrected, it may not be reflected in the dev server. In that case, stop the dev server and delete all files in the `node_modules/.vite` directory. You can also run it with the `clean:hard` command.
